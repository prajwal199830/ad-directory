What is VMAP?

VMAP, or Video Multiple Ad Playlist, is an XML-based standard used to describe advertising opportunities within video content. It allows publishers and video platforms to define where advertising breaks can occur, such as pre-roll, mid-roll and post-roll.

Common VMAP break types

VMAP commonly uses break types such as linear and nonlinear. The validator checks the values and highlights potentially unexpected configurations.

Common time offsets

A VMAP timeOffset can represent a percentage, a clock time such as 00:05:00, or special values such as start and end.

VMAP Validation for Publishers

A correctly structured VMAP response helps video players understand when and how advertising breaks should be requested. Publishers and video developers can use this validator to identify common XML and configuration issues before deploying VMAP responses.

VMAP and VAST

VMAP defines the advertising schedule while VAST commonly provides the actual video advertising response. A VMAP document can reference a VAST resource using an AdTagURI or include VAST data directly through an AdSource.

VMAP Pre-Roll, Mid-Roll and Post-Roll

VMAP can define advertising breaks at different points in a video. Pre-roll occurs before the main content, mid-roll occurs during playback and post-roll occurs after the content. Correct timeOffset values are important for these breaks to work as expected.
