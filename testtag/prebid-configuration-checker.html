About the Prebid.js Configuration Checker

Prebid.js is an open-source header bidding framework commonly used by publishers to connect multiple demand partners before sending an advertising request to an ad server such as Google Ad Manager.

What Does This Tool Check?

  • Prebid.js ad unit structure
  • Ad unit codes
  • Media types such as banner, video and native
  • Bidder configuration
  • Bidder parameters
  • Banner sizes
  • Duplicate ad unit codes
  • Missing bid configurations
  • Common configuration mistakes

Important Note

This tool performs static configuration checks. It does not execute Prebid.js, contact bidder endpoints, verify bidder account credentials or guarantee that an auction will work correctly in production.

A configuration can pass these checks and still experience problems caused by bidder parameters, consent requirements, browser restrictions, network requests, timeout settings or publisher implementation issues.
