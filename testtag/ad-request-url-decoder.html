What is an Ad Request URL?

An ad request URL is a URL used by an advertising platform, ad server, SDK or video player to request advertising information. It can contain many parameters describing the publisher, ad placement, device, content, targeting and other request details.

Why decode an ad request?

Advertising request URLs can become difficult to read because parameter values are often URL encoded. Decoding the URL makes it easier to understand the information being passed between advertising systems.

Common advertising URL parameters

  • sz / size — ad slot dimensions
  • iu — inventory or ad unit path
  • site — website or domain information
  • description_url — content or page URL
  • correlator — request/cache-busting value
  • output — requested response format
  • env — advertising environment
  • gdfp_req — Google ad request indicator

URL encoding

Characters such as spaces, ampersands and special characters can be encoded inside URLs. For example, %20 represents a space and %3A represents a colon. This tool converts URL-encoded values into a readable format.
