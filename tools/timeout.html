What Is Header Bidding Timeout?

A header bidding timeout is the maximum amount of time a publisher allows participating demand partners to respond to a header bidding auction. If a bid does not respond within the configured timeout, that response may not participate in the auction.

Why Does Header Bidding Timeout Matter?

Timeout settings involve a balance between demand competition and page performance. A longer timeout can give demand partners more time to respond, while an excessively long timeout can increase latency and potentially affect the user experience.

How Does This Calculator Work?

The calculator uses the number of auctions, configured timeout, average bid response time and observed timeout rate to estimate completed auctions and auctions that may time out. An optional CPM is used to provide a simple estimate of potential revenue associated with timed-out auctions.

What Is a Good Header Bidding Timeout?

There is no universal timeout value that works for every publisher. The appropriate setting depends on the demand partners being used, traffic geography, device mix, auction architecture, latency requirements and overall page performance.

How Can Publishers Reduce Timeouts?

Publishers can analyze individual demand partner response times, remove consistently slow partners, optimize bidder configuration and monitor timeout rates. Server-side solutions can also be considered where appropriate to reduce browser-side processing and latency.

Important Note

This calculator provides an estimate and should not be treated as a measurement of actual auction performance. Real header bidding results depend on bidder-specific response times, auction configuration, floors, traffic, browser conditions and other technical factors.
