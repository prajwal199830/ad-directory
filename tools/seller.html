What is sellers.json?

sellers.json is an industry standard used in digital advertising to provide information about sellers and intermediaries involved in the programmatic advertising supply chain.

The file helps buyers understand who is authorized to sell advertising inventory and provides transparency into the entities involved in the supply chain.

What does this validator check?

  • JSON syntax and structure
  • Presence of the sellers array
  • Seller ID availability
  • Seller ID duplicates
  • Seller type validity
  • Missing seller names
  • Missing seller domains
  • Invalid seller records

Valid Seller Types

The commonly used seller types are:

  • PUBLISHER — An entity that directly owns or monetizes advertising inventory.
  • INTERMEDIARY — An entity that facilitates the sale of advertising inventory.
  • BOTH — An entity that can act as both a publisher and an intermediary.

Important

This validator checks the structure and common formatting requirements of the supplied file. A successful validation does not necessarily confirm that every seller or company listed in the file is legitimately authorized to sell inventory.
